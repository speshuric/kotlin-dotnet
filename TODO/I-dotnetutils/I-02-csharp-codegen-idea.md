# I-02: Генерация C#-кода по Kotlin («на подумать», не прорабатывать сейчас)

- **Тема:** I. dotnetutils (идея на будущее)
- **Разметка:** POST-PoC (исследование), приоритет низкий
- **Статус:** TODO (идея)

## Суть идеи

Если порт SRM (I-01) сработает, сделать генерацию **C#-кода** по
Kotlin-коду. Это выстраивает механизацию проработки кейсов:

1. Пишется код на Kotlin и его ручной аналог на C#.
2. Агент пишет генерацию C# из Kotlin-IR.
3. Сгенерированный C# компилируется настоящим Roslyn.
4. По `ildasm` результата видно эталонную реализацию конструкций
   (как Roslyn lowering переводит конструкции в IL) — по ней можно
   прикидывать/сверять собственную IL-генерацию компилятора.

Польза: быстрое получение «правильного» IL для сложных кейсов
(лямбды, замыкания, дженерики, свойства) без ручного вывода.

## Заметки

- Не путать с целевым pipeline: это **инструмент исследования**, а не
  продакшн-путь компиляции.
- Возможная база: тот же IR-visitor, что и для IL-генерации, но с
  эмиттером C#-текста.
- Прорабатывать только после стабилизации Phase 10–12 и рабочего
  dotnetutils.

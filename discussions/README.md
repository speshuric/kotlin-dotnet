сессий и скрипты.

| Файл | Описание |
|---|---|
| `chat-export-1786958489540.json` | Исходное обсуждение концепции (plan-mode): архитектура, маппинг типов, дженерики, план работ. Источник для `AGENTS.md`. |

## Добавление новых файлов

Файлы в `discussions/` по умолчанию gitignored (кроме README/.gitkeep и
явно перечисленных в `.gitignore` через `!`-правила).

Чтобы добавить новый экспорт:

1. Положить файл в `discussions/`.
2. Добавить `!discussions/<filename>` в `.gitignore` (в блоке `# Discussions:`).
3. `git add discussions/<filename>`.

Хранить только значимые обсуждения и логи, не сырые дампы всех сессий.
